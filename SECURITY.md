# Security Policy

## Supported Versions

The project maintains the latest published version for security review and issue remediation. Older versions may receive limited support only when required for compatibility.

## Reporting a Vulnerability

GitHub Security Advisories is the single supported reporting channel for suspected security vulnerabilities. Reports are private: only the maintainer can see them until an advisory is published.

1. Open the repository Security tab, choose Advisories, and click "Report a vulnerability".
2. Include a clear description, reproduction steps, impact assessment, and any relevant proofs of concept.
3. Do not open a public issue, discussion, or pull request for a suspected vulnerability.

## Disclosure Timeline

We aim to acknowledge valid reports within 5 business days and provide a remediation plan or resolution status as quickly as possible. Complex issues may require additional investigation time, but we will keep the reporter informed.

We follow a coordinated disclosure window of 90 days from acknowledgment, or until a fix is released, whichever comes first. Reporters will be credited in the advisory unless they prefer to remain anonymous.

## Responsible Disclosure

We ask researchers and users to avoid exposing sensitive details publicly before a fix is available. Please do not share exploit details in public discussion forums or in open issues that could affect other users.

## Scope

This policy applies to the repository contents, project documentation, and any build or automation scripts shipped within this project.
